Descripción general

Aplicación Angular creada desde cero como ejercicio de aprendizaje de los fundamentos del framework. Consta de dos páginas navegables implementadas como Standalone Components, con routing configurado y uso de las nuevas Signals de Angular.

Estructura del proyecto

Ruta URL Componente Archivo
/ CounterpageComponent pages/counter/counter.page.components.ts
/hero HeroPageComponent pages/hero/hero-page.components.ts

La navegación entre páginas se gestiona desde app.html con <router-outlet> y enlaces routerLink.

Página 1 — Counter

Contador numérico que comienza en 10. El estado se almacena en una propiedad de clase normal (sin Signals).

  • Botones para incrementar: +1, +5, +10
  • Botón para resetear el contador a 100
  • Usa event binding con (click)="increaseby(n)"
  • Muestra el valor con interpolación: {{ counter }}

Métodos del componente

MétodoDescripción
increaseby(value) Suma value al contador (por defecto +1)
resetcounter(value) Fija el contador al valor indicado (por defecto 100)

Página 2 — Hero

Componente más avanzado que gestiona el estado mediante Signals, la nueva primitiva reactiva de Angular.

  • Estado inicial: name = signal('Ironman'), age = signal(45)
  • Los valores se leen en la plantilla con {{ name() }} (llamada de función)

Métodos del componente

MétodoQué haceAPI de Signal
changeHero() Cambia a Spiderman, 25 años .set()
changeAge() Incrementa la edad en +1 .update(age => age + 1)
getHeroDescription() Devuelve string combinado nombre + edad Computed manual
changeHeroDescription() Nombre a mayúsculas y edad +1 .update()
resetForm() Limpia nombre y edad a vacío/0 .set('')

Conceptos Angular practicados

Routing

Configuración de Routes[], RouterOutlet y RouterLink para navegación sin recarga.

Standalone Components

Componentes con standalone: true, sin necesidad de declararlos en un NgModule.

Signals

signal(), .set() y .update() para gestión de estado reactivo moderno.

Data Binding

Interpolación {{ }} y event binding (click) para conectar lógica y plantilla.

Separación en páginas

Estructura src/app/pages/ con cada página en su propia carpeta (HTML, CSS, TS).

Signals vs propiedades

Counter usa propiedad normal; Hero usa Signals — comparación directa de ambos enfoques.
